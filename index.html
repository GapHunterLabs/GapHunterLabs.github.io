Methodology

  • Every number on this page — downloads, pricing, rating, first-published date, GitHub ★ — comes straight from JetBrains Marketplace and GitHub's own public data. Nothing here is estimated or made up.
  • Growth compares each plugin's current downloads against the earliest point we have real data for it, not just the last time this page was refreshed — that's why the baseline date under the % can vary from plugin to plugin. A plugin with no earlier data point yet shows "—" instead of a guess.
  • A plugin marked Pending was recently submitted to Marketplace and is still in moderation — its listing exists, it just isn't indexed for search yet. That's normal review turnaround, not a problem with the plugin.

The Gap / The Fix

  • The Gap is the real, cited evidence that this plugin needed to exist — a documented pattern of complaints about an existing tool (reviews, ratings, recurring bug reports), not a guess about what developers might want.
  • The Fix is the plugin's own real, published description of what it actually does. Neither side is generated or embellished — every claim traces back to something publicly verifiable.

What's Never Stored Here

  • We never publish a competitor's private marketplace identifiers or a vendor's personal contact details (email, phone, address) — even when the public API we read from happens to expose them alongside the data we do use.
  • "Visitors today" counts real visits via GoatCounter — cookie-free, no IP address stored, no individual visitor ever identifiable. It counts sessions, not raw pageviews, so reloading this page or browsing multiple sections doesn't inflate the number.
