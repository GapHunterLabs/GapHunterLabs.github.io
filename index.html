Methodology: downloads, pricing model, first-published date, and reviews come from searchPlugins//plugins/<id>/comments in JetBrains Marketplace's public API, never estimated. GitHub ★ comes from gh repo view. "Growth" compares against the earliest known snapshot for each plugin, not just the previous run (hover the % to see the baseline date and starting value) — a plugin with no earlier snapshot shows "—". The 2026-08-07 snapshot (25 plugins) was confirmed directly by the team, not pulled from an archived API snapshot — it's still used as a real growth baseline, marked as such in out/catalog_history.json. Every snapshot from 2026-08-11 onward comes from the live API. The 7 plugins marked Pending were submitted to Marketplace on 2026-08-14 and aren't indexed in searchPlugins yet — normal during moderation, not an error in this report.

What's never stored here: Marketplace product codes (productCode) or vendor contact details (email/phone/address) — the API exposes them, but they're explicitly discarded before anything is written to disk, the same rule followed across every repo in this catalog.
