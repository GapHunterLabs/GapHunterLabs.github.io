!The gap it fixes

Reordering or inserting a value in the middle of the enum after data has already been persisted silently corrupts existing records (the stored ordinal no longer corresponds to the same constant) -- a well-documented fragility (Baeldung and official JPA persistence guides). No Marketplace plugin found that flags it, despite several enum-tooling plugins existing.
