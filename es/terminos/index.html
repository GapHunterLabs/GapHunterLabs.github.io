Términos de servicio

Qué es este catálogo, qué no es y quién responde por qué.

Fecha de vigencia: 12 de octubre de 2026

Aceptación de estos términos

Al usar gaphunterlabs.com (“este sitio”), aceptas estos términos. Si no estás de acuerdo, no uses el sitio; no hay ninguna cuenta que cerrar ni nada más que hacer.

Qué es este sitio

Este sitio es un catálogo informativo: indexa, describe y enlaza plugins de la familia JetBrains y de VS Code que construí, usando datos públicos de JetBrains Marketplace, el Marketplace de VS Code y GitHub. El sitio no vende, aloja, distribuye ni licencia ningún plugin directamente. También presenta los servicios de consultoría independientes que ofrezco (ver “Servicios de consultoría” más abajo); los acuerdo y presto por separado, bajo sus propios términos escritos, no a través de este sitio.

Tiendas de terceros

La instalación o la compra de cualquier plugin listado aquí ocurre por completo en JetBrains Marketplace o en Visual Studio Code Marketplace, no en este sitio. JetBrains o Microsoft gestionan los pagos, las facturas y los reembolsos según sus propios términos. La licencia de uso de cada plugin es la del propio plugin: los plugins de pago para JetBrains se licencian bajo el Acuerdo de Licencia de Usuario Final de Gap Hunter Labs, y todo el código fuente de los plugins se publica bajo la Licencia Apache 2.0. JetBrains y Microsoft no son parte de esa licencia.

Servicios de consultoría

Aparte del catálogo de plugins, ofrezco servicios de ingeniería pagos — como una auditoría de rendimiento de alcance cerrado de un plugin de IntelliJ, actualizaciones de plugins para versiones nuevas del IDE, revisiones de seguridad de dependencias y CI/CD, y plugins a medida. Estos servicios no se venden ni se contratan a través de este sitio. Acuerdo cada encargo directamente con el cliente en una cotización o un acuerdo escrito aparte que fija su propio alcance, precio, entregables, garantía y responsabilidad. Nada en este sitio es una oferta aceptable por sí misma, una cotización vinculante ni una garantía de un resultado específico; los términos que rigen cualquier encargo son los de la cotización o el acuerdo firmado, no los de este sitio. Contactarme a través de este sitio no crea ninguna obligación para ninguna de las partes hasta que exista ese acuerdo escrito.

Exactitud de la información

Las cifras de descargas, valoraciones, precios, estrellas de GitHub y datos similares de este sitio provienen de API públicas (plugins.jetbrains.com y la API de GitHub) con un ciclo de actualización periódico. Reflejan una instantánea, no necesariamente el valor en vivo en el momento en que lees esta página. Este sitio se ofrece “tal cual”, sin garantía de ningún tipo, expresa o implícita, incluidas la exactitud, la integridad o la idoneidad para un fin concreto. Si encuentras algo incorrecto, repórtalo y lo corregiré, pero no se garantiza exactitud en tiempo real.

Marcas registradas

JetBrains, IntelliJ IDEA, WebStorm, PyCharm y las marcas relacionadas son marcas registradas de JetBrains s.r.o. Visual Studio Code es una marca registrada de Microsoft Corporation. GitHub es una marca registrada de GitHub, Inc. Estos nombres aparecen en este sitio solo para describir la compatibilidad de los plugins y sus fichas en las tiendas. Este sitio y sus plugins son independientes y no están afiliados, patrocinados ni respaldados por JetBrains, Microsoft ni GitHub.

Propiedad intelectual

El diseño, los textos y el contenido original de este sitio son míos. El código fuente de los plugins está en su propio repositorio público en github.com/GapHunterLabs y se rige por la licencia de ese repositorio, no por estos términos. Los plugins de pago, tal como se distribuyen en JetBrains Marketplace, también se rigen por el Acuerdo de Licencia de Usuario Final.

Uso aceptable

No hagas scraping de este sitio a un ritmo que lo degrade para los demás, no intentes eludir sus medidas de seguridad y no uses el flujo de contacto para enviar nada ilegal, abusivo o fraudulento. El acceso automatizado razonable y de bajo volumen (por ejemplo, un verificador de enlaces) está bien.

Limitación de responsabilidad

En la máxima medida permitida por la ley, no acepto responsabilidad por daños indirectos, incidentales o consecuentes que surjan del uso de este sitio o de cualquier plugin obtenido a través de un marketplace enlazado. Tu relación con el marketplace y con el plugin en sí (su propia licencia, sus propios términos) rige tu uso de ese plugin. Este sitio es un catálogo informativo y un punto de contacto; no es en sí mismo el producto ni el servicio. Cualquier encargo pago se rige por su propio acuerdo escrito, cuyos términos de responsabilidad prevalecen sobre esta sección para ese encargo.

Ley aplicable

Opero este sitio desde Colombia como persona natural, no como una empresa registrada. Estos términos se rigen por las leyes de Colombia, sin tener en cuenta sus normas sobre conflicto de leyes.

Cambios en estos términos

Si estos términos cambian, esta página se actualizará y la fecha de vigencia de arriba cambiará en consecuencia. Seguir usando el sitio después de un cambio significa que aceptas los términos actualizados.
