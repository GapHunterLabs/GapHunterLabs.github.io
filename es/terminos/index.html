Términos de servicio

Qué es este catálogo, qué no es y quién responde por qué.

Fecha de vigencia: 8 de octubre de 2026

Aceptación de estos términos

Al usar gaphunterlabs.github.io (“este sitio”), aceptas estos términos. Si no estás de acuerdo, la única vía es no usar el sitio — no hay ninguna cuenta que cerrar ni nada más que hacer.

Qué es este sitio

Este sitio es un catálogo informativo: indexa, describe y enlaza plugins para la familia JetBrains y VS Code creados por Gap Hunter Labs, con datos públicos de JetBrains Marketplace, VS Code Marketplace y GitHub. Este sitio no vende, aloja, distribuye ni licencia ningún plugin directamente.

Tiendas de terceros

La instalación o la compra de cualquier plugin listado aquí ocurre por completo en JetBrains Marketplace o en Visual Studio Code Marketplace — no en este sitio. JetBrains o Microsoft gestionan los pagos, las facturas y los reembolsos según sus propios términos. La licencia de uso de cada plugin es la del propio plugin: los plugins de pago para JetBrains se licencian bajo el Acuerdo de Licencia de Usuario Final de Gap Hunter Labs, y todo el código fuente de los plugins se publica bajo la Licencia Apache 2.0. JetBrains y Microsoft no son parte de esa licencia.

Exactitud de la información

Las cifras de descargas, valoraciones, precios, estrellas de GitHub y datos similares de este sitio provienen de API públicas (plugins.jetbrains.com y la API de GitHub) con un ciclo de actualización periódico — reflejan una instantánea, no necesariamente el valor en vivo en el momento exacto en que lees esta página. Este sitio se ofrece “tal cual”, sin garantía de ningún tipo, expresa o implícita, incluidas la exactitud, la integridad o la idoneidad para un fin concreto. Si encuentras algo incorrecto, repórtalo — se corregirá, pero no se garantiza exactitud en tiempo real.

GitHub es una marca registrada de GitHub, Inc. Propiedad intelectual

El diseño, los textos y el contenido original de este sitio pertenecen a Gap Hunter Labs. El código fuente de los plugins está en su propio repositorio público en github.com/GapHunterLabs y se rige por la licencia de ese repositorio, no por estos términos. Los plugins de pago, tal como se distribuyen en JetBrains Marketplace, también se rigen por el Acuerdo de Licencia de Usuario Final.
