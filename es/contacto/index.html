Volver al inicio

Si reportas un problema de un plugin

Incluye lo necesario para reproducirlo:

  • Nombre y versión del plugin (Settings → Plugins)
  • Nombre y versión del IDE
  • Qué esperabas y qué pasó en cambio
  • Pasos para reproducirlo, en un proyecto nuevo o no
  • Stack trace o fragmento de log que se pueda compartir

Qué esperar

No hay un SLA de tiempo de respuesta publicado. Los issues de GitHub se quedan en el repositorio del plugin, y el correo va a la dirección publicada en este sitio. No hay teléfono, dirección postal ni formulario con servidor.

Qué hace útil un reporte

  1. 1El problema¿Qué fricción estás encontrando?
  2. 2El entornoIDE, lenguaje, framework o flujo de trabajo.
  3. 3Soluciones existentes¿Qué has probado?
  4. 4EvidenciaEnlaces, capturas o referencias.
  5. 5Impacto¿Por qué importa este problema?
