Metodología

Cómo se evalúan las ideas de plugins, qué significan las cifras del catálogo y qué deja fuera este sitio a propósito.

Metodología

  • Cada cifra de esta página — descargas, precio, valoración, fecha de primera publicación, GitHub ★ — viene directamente de los datos públicos de JetBrains Marketplace y GitHub. Nada aquí es una estimación ni está inventado.
  • Crecimiento compara las descargas actuales de cada plugin con el primer punto con datos reales, no solo con la última vez que se actualizó esta página — por eso la fecha base bajo el % puede variar de un plugin a otro. Un plugin sin un punto de datos anterior muestra “—” en lugar de una estimación.
  • Un plugin marcado como Pendiente se envió hace poco a Marketplace y sigue en moderación — su ficha existe, solo que todavía no aparece en las búsquedas. Es el tiempo normal de revisión, no un problema del plugin.

La brecha / La solución

  • La brecha es la evidencia real y citada de que este plugin necesitaba existir — un patrón documentado de quejas sobre una herramienta existente (reseñas, valoraciones, reportes de errores recurrentes), no una suposición sobre lo que los desarrolladores podrían querer.
  • La solución es la descripción real y publicada del propio plugin sobre lo que hace. Ninguna de las dos partes se genera ni se adorna — cada afirmación remite a algo verificable públicamente.

Reseñas, valoración y estrellas

  • Las reseñas, la valoración en Marketplace y las estrellas de GitHub usan las mismas fuentes públicas que las descargas. Este catálogo todavía es joven y está centrado en el producto, así que esas cifras viven aquí — no en la portada — hasta que describan el trabajo en lugar de celdas vacías.

Lo que nunca se guarda aquí

  • Nunca se publican identificadores privados de un competidor en las tiendas ni datos de contacto personales de un proveedor (correo, teléfono, dirección) — aunque la API pública que consulta este catálogo los exponga junto a los datos que sí usa.
  • “Visitantes de hoy” cuenta visitas reales con GoatCounter — sin cookies, sin guardar direcciones IP y sin identificar nunca a ningún visitante. Cuenta sesiones, no páginas vistas en bruto, así que recargar esta página o recorrer varias secciones no infla la cifra.
