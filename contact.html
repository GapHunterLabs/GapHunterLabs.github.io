Contact

Gap Hunter Labs hunts real, evidence-based gaps in developer tooling and ships focused IntelliJ-family plugins to fix them. This page lists the public channels we actually publish — not a form that goes nowhere, and not a made-up office or phone number.

Who this is for

  • Plugin support. If a plugin misbehaves, fails to install, or you have a concrete bug or feature request, use that plugin’s own GitHub repository or its JetBrains Marketplace listing. Those are the per-product public channels.
  • Catalog or site questions. If something on this catalog looks wrong (a listing, a metric, methodology copy), email us or open an issue on the relevant GitHub repo when the question is about a specific plugin.
  • Partnerships and press. Use the email below or the LinkedIn profile linked from this site. We do not publish a company phone number or a street address.

How to reach us

  • GitHub organization Each plugin is a public repository under github.com/GapHunterLabs. Open an issue on the plugin’s repo. The catalog on the homepage links each product to its repository.
  • JetBrains Marketplace Vendor page: plugins.jetbrains.com/vendor/gap-hunter-labs. Reviews and comments on a plugin’s Marketplace listing are a public channel for that product.
  • Email The address published on this site is gaphunterlabs@gmail.com. Use it for catalog questions, partnerships, and anything that is not tied to a single plugin repo.
  • LinkedIn The public profile linked from this site: linkedin.com/in/joel-diaz-82687b428. There is no separate company LinkedIn page that we publish.

If you are reporting a plugin issue

Please include enough to reproduce it. A useful report usually has:

  • Plugin name (and version, from Settings → Plugins)
  • IDE name and version (for example IntelliJ IDEA 2024.3, or Android Studio)
  • What you expected, what happened instead
  • Steps to reproduce, and whether it happens in a fresh project
  • Any stack trace or idea.log excerpt that is safe to share (no secrets, license keys, or private source)

What to expect

We do not publish a response-time SLA. GitHub issues stay on the plugin’s repository; Marketplace reviews and comments stay on that listing. Email is the address this site already publishes in its organization metadata. We have not published a phone number, a mailing address, or a web form with a backend — none of those are omitted by accident.
