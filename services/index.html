Plugin updates for new IDE versions

Your plugin built and verified against the IntelliJ versions you need to support: removed or deprecated APIs, Kotlin K2 mode, IntelliJ Platform Gradle Plugin 2.x and Plugin Verifier failures. Dependency and CI/CD security review

A read-only review of the repositories you choose: known vulnerabilities in production dependencies, dependency-confusion risks in manifests and lockfiles, and CI/CD workflow permissions, checked with OSV-Scanner and OpenSSF Scorecard. Optional EU Cyber Resilience Act readiness check: security policy, security.txt, SBOM and the vulnerability-reporting workflow (technical, not legal advice). The written report gives each finding with its source and the version that fixes it, when one exists. Anything exploitable is reported first through your security channel.
