Methodology

How plugin ideas are evaluated, what the catalog’s figures mean, and what this site deliberately leaves out.

Methodology

  • Every number on this page (downloads, pricing, rating, first-published date, GitHub ★) comes straight from JetBrains Marketplace and GitHub's own public data. Nothing here is estimated or made up.
  • Growth compares each plugin's current downloads with the earliest data point recorded for it, not with the last refresh of this page. That's why the baseline date under the % differs from plugin to plugin. A plugin without an earlier data point shows "—" instead of a guess.
  • A plugin marked Pending was recently submitted to Marketplace and is still in moderation: the listing exists but isn't indexed for search yet. That's the normal review time, not a problem with the plugin.

The Gap / The Fix

  • The Gap is the cited evidence that the plugin was needed: a documented pattern of complaints about an existing tool (reviews, ratings, recurring bug reports).
  • The Fix is the plugin's own published description of what it does. Neither side is embellished, and every claim traces back to something you can check in public.

Reviews, rating, and stars

  • Reviews, Marketplace rating, and GitHub stars use the same public sources as downloads. The catalog is still young, so those figures stay on this page, out of the hero, until there are enough of them to say something.

What's Never Stored Here

  • A competitor's private marketplace identifiers or a vendor's personal contact details (email, phone, address) are never published, even when the public API this catalog reads from exposes them next to the data it uses.
  • "Visitors today" counts visits with GoatCounter, which uses no cookies, stores no IP address and can't identify individual visitors. It counts sessions, not raw pageviews, so reloading this page or browsing several sections doesn't inflate the number.
