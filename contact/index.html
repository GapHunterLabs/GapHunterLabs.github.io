If you're reporting a plugin issue

Include enough to reproduce it:

  • Plugin name and version (Settings → Plugins)
  • IDE name and version
  • What you expected, what happened instead
  • Steps to reproduce, fresh project or not
  • Stack trace/log excerpt safe to share

What to expect

No published response-time SLA. GitHub issues stay on the plugin's repository. Email is the address this site already publishes — no phone number, mailing address, or backend form, none omitted by accident.

What makes a useful report

  1. 01The problemWhat friction are you experiencing?
  2. 02The environmentIDE, language, framework or workflow.
  3. 03Existing solutionsWhat have you tried?
  4. 04EvidenceLinks, screenshots, or references.
  5. 05ImpactWhy does this problem matter?
